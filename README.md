# GenAI 기초 1: LLM 기반 업무 자동화

"LLM 기반 업무 자동화" 미션의 결과물을 담은 저장소입니다.
동일한 업무 과업(보고서 개요 작성)을 3종 이상의 LLM에 수행시켜 비교하고,
최적 모델을 선정한 뒤, 페르소나 기반 시스템 프롬프트를 설계하고
Few-shot 예시와 단계적 추론 유도 기법을 적용해 개선한 과정을 정리했습니다.

## 선택한 업무 과업

**보고서 개요 작성** — 경영진 보고 상황과 포함할 항목을 입력받아
`[목차 / 섹션별 요약 / 확인 필요 항목]` 3단 형식으로 개요를 생성하는 자동화 과업.

## 주요 학습 내용

- LLM은 확률적으로 다음 토큰을 생성하는 구조이며, 이 특성 때문에
  근거 없는 사실을 그럴듯하게 만들어내는 환각(Hallucination) 현상이 발생한다.
- Zero-shot보다 Few-shot, 그리고 단계적 추론을 유도하는 프롬프트가
  형식 준수와 정확도 면에서 더 안정적인 결과를 만든다.
- 모델 선택은 "느낌"이 아니라 정확성, 형식 적합도, 파이프라인 일관성 등
  구체적인 평가 축과 근거로 판단해야 한다.
- 시스템 프롬프트에 "모르면 모른다고 말하기" 같은 안전장치를 넣어도
  환각이 완전히 방지되지는 않는다. 이는 모델이 확률적으로 다음 토큰을
  생성하는 구조와 자기 지식 경계에 대한 불완전한 인식(calibration 문제)
  때문이며, 실제 검증 과정(`03_execution_log.md`, Turn 10)에서도
  이 한계가 관찰되었다.
